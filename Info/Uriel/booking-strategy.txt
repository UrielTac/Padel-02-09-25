## 1. Análisis del Flujo Actual

- Recopila datos de múltiples pasos

## 2. Estrategia de Implementación

### 2.1 Modificaciones Necesarias en SummaryPreview

1. **Estado y Manejo de Carga**
```typescript
const [isProcessing, setIsProcessing] = useState(false);
const [bookingError, setBookingError] = useState<string | null>(null);
```

2. **Función de Reserva**
```typescript
const handleBooking = async () => {
  setIsProcessing(true);
  setBookingError(null);
  
  try {
    // Obtener datos del contexto del formulario
    const bookingData = transformFormDataToBookingData();
    
    // Llamar al servicio
    const result = await bookingService.createBooking(bookingData);
    
    if (result.error) throw new Error(result.error.message);
    
    // Actualizar caché y mostrar éxito
    await queryClient.invalidateQueries(['bookings']);
    toast.success('Reserva creada exitosamente');
    
    // Redireccionar o cerrar
    handleSuccess();
  } catch (error) {
    setBookingError(error.message);
    toast.error(error.message || 'Error al crear la reserva');
  } finally {
    setIsProcessing(false);
  }
};
```

3. **Transformación de Datos**
```typescript
const transformFormDataToBookingData = (): BookingCreationData => {
  const { location, shift, items, payment } = formContext;
  
  return {
    courtId: shift.courtId,
    date: shift.date,
    startTime: shift.startTime,
    endTime: shift.endTime,
    courtPrice: payment.courtPrice,
    rentalItemsPrice: payment.rentalItemsPrice,
    paymentStatus: payment.status,
    paymentMethod: payment.method,
    depositAmount: payment.deposit,
    participants: transformParticipants(location.participants),
    rentalItems: transformRentals(items.selectedItems)
  };
};
```

### 2.2 Validaciones Necesarias

1. **Pre-reserva**
```typescript
const validateBookingData = () => {
  const validations = [
    { condition: !shift.courtId, message: 'Selecciona una cancha' },
    { condition: !shift.date, message: 'Selecciona una fecha' },
    { condition: !payment.method, message: 'Selecciona un método de pago' },
    // ... más validaciones
  ];

  const error = validations.find(v => v.condition);
  if (error) throw new Error(error.message);
};
```

2. **Disponibilidad**
```typescript
const checkAvailability = async () => {
  const result = await bookingService.checkAvailability({
    courtId: shift.courtId,
    date: shift.date,
    startTime: shift.startTime,
    endTime: shift.endTime
  });

  if (result.error) throw new Error(result.error.message);
  return result.data;
};
```

### 2.3 Manejo de UI/UX

1. **Estados de Carga**
```typescript
// Botón de reserva
<Button
  onClick={handleBooking}
  disabled={isProcessing || !isValid}
  className={cn(
    "w-full",
    isProcessing && "opacity-50 cursor-not-allowed"
```
